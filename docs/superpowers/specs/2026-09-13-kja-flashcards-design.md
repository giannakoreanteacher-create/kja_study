# 한국어 단어 Quizlet(단어카드) 웹사이트 설계

## 배경 / 목표
`한국어 학습용 어휘 목록.xls` (국립국어원 한국어 학습용 어휘 목록, 총 5,965단어 — 1단계/A 982개, 2단계/B 2,111개, 3단계/C 2,872개, 가나다순)를 이용해, 사용자가 단계를 고르면 그 단계의 한국어 단어가 랜덤으로 카드 앞면에 나오고, 클릭하면 뒤집혀 영어 뜻이 보이는 개인용 단어카드 웹사이트를 만든다.

## 원본 데이터 확인 결과
컬럼: 순위 / 단어 / 품사 / 풀이 / 등급

- 등급(A/B/C)별 개수는 982 / 2,111 / 2,872로 요청사항과 일치 확인.
- **"풀이" 컬럼에는 영어 뜻이 없음.** 한자어(예: 가격03→價格)나 예시 연어(예: 가로01→"~와 세로") 정도이며, 5,965개 중 4,009개만 값이 있고 나머지는 빈 값. → 영어 뜻은 별도로 생성해야 함 (아래 "데이터 준비" 참고).
- "순위" 컬럼은 고유 ID로 쓸 수 없음 (5,965개 중 중복 제외 고유값 5,898개 — 67개 중복 존재 확인). → 데이터 생성 시 배열 인덱스를 새 고유 id로 부여한다.

## 아키텍처
정적 프론트엔드 + 아주 얇은 Node.js(Express) 서버. 프레임워크·빌드 도구·데이터베이스 없음. API 없음(외부 호출도, API 키도 없음) — Express는 오직 정적 파일 서빙 용도.

```
kja_study/
├── server.js          # express.static(public/) 만 하는 서버, PORT 기본값 5000
├── package.json        # "start": "node server.js"
└── public/
    ├── index.html
    ├── style.css
    ├── app.js          # 화면 전환 / 카드 뒤집기 / 스와이프 / localStorage 로직
    └── words.js         # 단어 데이터 (전역 변수로 정의, <script> 태그로 로드)
```

- 로컬 실행: `npm install` → `npm start` → `http://localhost:5000`
- 배포: GitHub 저장소 → Render "Web Service" 연결 (무료 티어), Build `npm install`, Start `npm start`. 무료 티어 특성상 일정 시간 무활동 시 슬립되며 첫 요청 시 기동에 시간이 걸릴 수 있음(개인용 프로젝트라 허용 가능한 수준으로 판단).
- 편집 환경: VS Code (설계에 영향 없음, 참고용).

## 데이터 준비 (코딩 전 1회성 작업)
1. xls의 5,965행을 파싱.
2. 각 행에 대해 영어 뜻(meaning)을 새로 생성 (Claude가 직접 작성, 사용자 확인 하에 진행).
3. `public/words.js`에 아래 형태의 배열로 저장:
   ```js
   const WORDS = [
     { id: 0, word: "가게", pos: "명", meaning: "shop / store", level: "A" },
     // ...
   ];
   ```
   - `id`: 배열 인덱스 기반 고유값 (원본 "순위"는 중복이 있어 사용 불가)
   - `level`: 원본 "등급" 그대로 A/B/C
4. 검증: 전체 5,965개 항목에 meaning이 채워졌는지, id 중복 없는지, 레벨별 개수가 982/2,111/2,872인지 스크립트로 확인.

## 화면 흐름
1. **홈 (레벨 선택)**
   - 1단계(A) / 2단계(B) / 3단계(C) 버튼 3개
   - 각 버튼에 오늘 학습 현황 표시 (예: "18/30 오늘 학습")
   - 그 단계에 누적 "모름" 단어가 1개 이상이면 "복습하기 (N개)" 버튼을 해당 레벨 아래 별도 표시
2. **학습 화면**
   - 진입 시: 그 레벨에서 아직 한 번도 안 본 단어 중, 오늘 남은 한도(하루 최대 30개, 레벨별 독립 카운트)만큼 랜덤으로 뽑아 큐를 만듦
   - 카드 앞면: 단어 + 품사 (예: "가깝다 / (형용사)")
   - 카드 클릭 → 뒤집혀 뒷면 표시: 영어 뜻
   - 뒷면을 본 뒤 좌우 스와이프: 왼쪽(모름) / 오른쪽(안다) → 다음 카드로. 큐가 끝날 때까지 중간에 끊기는 화면 없이 이어서 진행 (10개 단위로 멈추지 않음)
   - "안다" 스와이프 시 그 단어는 모름 목록에 없으면 아무 변화 없음
   - "모름" 스와이프 시 그 단어를 해당 레벨의 누적 모름 목록에 추가(이미 있으면 유지)
3. **완료 화면**
   - 오늘 한도(30개)를 다 썼거나, 그 레벨의 모든 단어를 이미 다 학습한 경우 진입
   - 간단한 완료 메시지 표시
   - 버튼: "복습하기" (모름 목록이 있을 때만) / "홈으로"
4. **복습 화면**
   - 그 레벨의 누적 "모름" 목록을 같은 방식(뒤집기 + 좌우 스와이프)으로 다시 봄
   - "안다"로 넘기면 그 단어는 모름 목록에서 완전히 제거됨
   - "모름"이면 목록에 그대로 유지
   - 목록을 다 돌면 짧은 완료 메시지 + 홈으로

## 데이터 저장 (localStorage, 레벨별로 키 분리: 예 `kja_progress_A`)
```js
{
  seenIds: [12, 87, ...],     // 이미 학습 화면에 등장한 적 있는 단어 id (새 단어 뽑을 때 제외 대상)
  wrongIds: [340, 12, ...],   // 누적 "모름" 목록
  today: "2026-09-13",         // 마지막 학습 날짜
  todayCount: 18                // 오늘 새로 학습한 개수 (오늘 날짜와 다르면 0으로 리셋)
}
```
- 브라우저별로만 유지되고 기기/브라우저 간 동기화는 없음 (개인용 목적에 맞춰 의도적으로 단순화, 로그인·서버 DB 없음)

## 예외 처리
- 레벨의 모든 단어를 이미 학습한 경우 → 학습 화면 진입 시 바로 완료 화면(축하 메시지)으로, 새 단어 없음
- 그 레벨에 모름 단어가 0개면 복습 버튼 자체를 숨김
- localStorage를 사용할 수 없는 환경(시크릿 모드 등)에서는 try/catch로 감싸 에러 없이 그 세션 동안만 메모리에 기억 (조용히 저하, 사용자에게 에러 노출 안 함)
- 데이터 생성 과정에서 영어 뜻이 비어있는 항목이 없도록 사전 검증 (있으면 배포 전 수정)

## 스타일
토스(Toss) 스타일 기반: 넉넉한 여백, 큰 둥근 모서리(카드/버튼), 부드러운 그림자, 큰 탭 영역. 색상은 회색+파랑 대신 베이비핑크를 포인트 컬러로 사용 (배경 화이트/아이보리, 카드·버튼에 부드러운 핑크 톤, 텍스트는 진한 회색/블랙). 폰트는 시스템 기본 산세리프 또는 Pretendard.

## 테스트
- 브라우저 수동 테스트: 레벨 선택 → 학습(카드 뒤집기·양방향 스와이프) → 완료 화면 → 복습 → 새로고침 후에도 진행 상황이 유지되는지, 날짜가 바뀐 것처럼 시뮬레이션했을 때 오늘 카운트가 리셋되는지
- 데이터 생성 스크립트에 대한 간단한 assert 체크: 5,965개 전부 meaning 존재, id 중복 없음, 레벨별 개수(982/2,111/2,872) 일치
